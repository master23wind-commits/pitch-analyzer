# 투구 폼 분석기

야구 투구 영상을 옆에서 찍어 올리면 AI가 관절을 찾아 **체중이동 · 골반-어깨 분리 · 관절 회전 순서 · 앞다리 버팀 · 릴리스**를 100점 만점으로 채점합니다. 10구 제구 기록(사람이 체크)을 함께 남기고, 결과 카드 이미지와 제출 코드로 선생님께 제출할 수 있습니다.

- 영상은 휴대폰 안에서만 처리되고 어디에도 올라가지 않습니다.
- 선생님은 화면 아래 "선생님용: 제출 코드 모으기"에 학생 제출 코드를 붙여 넣어 표·CSV로 정리합니다.
- 포즈 인식: MediaPipe Pose (Apache-2.0). 모델 파일은 `mp/`에 들어 있습니다.

만든 사람: 체육교사 이태성
